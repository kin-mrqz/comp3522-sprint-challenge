# data/

Put the Moodle files in `data/raw/`. Notebook 02 writes `data/processed/analysis_frame.parquet`. Notebook 03 writes `features.parquet`. Notebook 04 writes `model_matrix.parquet`.

Commit a raw file only when it is under GitHub's 100MB limit. The repository is private because these files are the unseen assessment. If a file is larger than that, leave it out and write here who has the local copy.

Do not copy the HKO weather tables from the course project into this folder. `context/hko/` is for citation only.
